# Web security review

1. Trace untrusted data from entry to storage, command, template, and response sinks.
2. Check authentication, authorization, session handling, and origin assumptions.
3. Look for injection, exposure, insecure defaults, and missing rate or size limits.
4. Verify findings against code and configuration; distinguish risk from confirmed exploitability.
5. Recommend the smallest control that closes the demonstrated path.
