# Implementation planning

1. Confirm the requested scope and inspect existing changes.
2. Order work from the earliest uncertainty to the smallest implementation step.
3. Pair each step with a check that can prove or falsify its result.
4. Keep the plan short enough to execute; split only where ownership or dependencies require it.
5. Do not create a plan document unless the user asked for one or it is needed for handoff.
