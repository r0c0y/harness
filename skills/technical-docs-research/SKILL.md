# Technical documentation research

1. Identify the exact product, version, and disputed technical claim.
2. Prefer current first-party documentation and specifications.
3. Cross-check important statements with release notes or source implementation.
4. Quote minimally, capture the source date, and distinguish documented fact from inference.
5. If only a known-URL fetch is available, do not imply that a broad web search was performed.
