# Agent behavior evaluations

1. Define the behavior under evaluation and the failure mode that matters.
2. Create representative tasks with expected evidence, tool bounds, and stop conditions.
3. Include both allowed and denied cases; avoid scoring only on the final prose.
4. Keep fixtures deterministic and isolate any model or network dependency.
5. Report pass criteria and raw observations; do not tune to a single example.
