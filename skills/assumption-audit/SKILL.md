# Assumption audit

1. Extract claims the proposed solution depends on.
2. Verify claims from source, tests, configuration, or observed runtime behavior.
3. Label unresolved items as assumptions and state what would disprove them.
4. Prioritize assumptions that affect safety, compatibility, or the selected project.
5. Do not present a guess as a discovered fact.
