# Root cause analysis

1. Build a short event timeline from logs, source, and user observations.
2. Separate direct cause, contributing conditions, and downstream impact.
3. Test whether removing the proposed cause would prevent the observed failure.
4. Identify a control that prevents recurrence and a signal that detects it early.
5. Label uncertain links in the chain instead of writing a confident but unsupported story.
