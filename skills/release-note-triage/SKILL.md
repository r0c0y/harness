# Release note triage

1. Confirm the exact current and target releases.
2. Filter changes for APIs, defaults, security, runtime support, and removed behavior used here.
3. Verify high-impact notes against linked issues or source changes.
4. Mark items irrelevant to this repo and explain the reason briefly.
5. Produce an upgrade risk list rather than claiming compatibility without a test.
