# Feature implementation

1. Find the relevant entry point, tests, and local conventions before editing.
2. Translate the request into observable behavior and identify the smallest owning module.
3. Change only what is required; preserve existing UI and public contracts.
4. Reuse existing dependencies and patterns rather than adding speculative abstractions.
5. Run relevant checks and summarize files changed, evidence, and any remaining limits.
