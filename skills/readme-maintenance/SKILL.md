# README maintenance

1. Check setup commands and defaults against the current source and configuration.
2. Order content around a new contributor's first successful run.
3. Include prerequisites, common failure signals, and safe cleanup guidance.
4. Keep claims versioned and remove obsolete or contradictory instructions.
5. Preserve unrelated sections and verify every command before marking it tested.
