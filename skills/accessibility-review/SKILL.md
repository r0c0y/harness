# Accessibility review

1. Inspect semantics, heading order, names for controls, and form error associations.
2. Check keyboard focus order and visible focus in source styles when evidence is available.
3. Consider reduced motion, zoom, and non-color status cues.
4. Separate statically verifiable findings from items needing assistive-technology testing.
5. Preserve the existing design; report concrete barriers and narrow corrections.
