# Dependency review

1. State the capability needed and check whether the runtime already provides it.
2. Compare a dependency-free option with a small set of maintained candidates.
3. Verify supported runtime, release activity, transitive footprint, and license from primary sources.
4. Explain update and security maintenance costs.
5. Do not install a package unless the user requested implementation and the project permits it.
