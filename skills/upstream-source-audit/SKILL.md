# Upstream source audit

1. Identify which organization owns the API, format, runtime, or package in question.
2. Trace each material claim to that owner's documentation, source, or release record.
3. Check that examples and cited paths exist at the stated revision.
4. Separate first-party evidence from commentary and community examples.
5. Record any unresolved contradiction without choosing the more convenient source.
