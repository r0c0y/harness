# API documentation research

1. Confirm provider and API version before comparing behavior.
2. Locate endpoint, schema, authentication, pagination, rate-limit, and error documentation from the provider.
3. Check whether examples match the current API version and transport.
4. Verify uncertain claims against a first-party schema or SDK implementation.
5. Summarize unknowns that require an account-specific test rather than guessing.
