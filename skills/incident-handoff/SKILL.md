# Incident handoff

1. State impact, current status, and the exact blocker in plain language.
2. Include reproduction, commands, relevant logs, and what has already been ruled out.
3. Separate verified facts from likely causes and open questions.
4. List the smallest safe next action and the prerequisite owner if blocked.
5. Omit secrets and avoid claiming a fix that has not been verified.
