# Scope control

1. List the requested outcome and the files or surfaces that must remain unchanged.
2. Inspect the existing diff before editing; preserve unrelated and uncommitted work.
3. Make the smallest change that satisfies the request.
4. Keep refactors, UI redesigns, new dependencies, and remote actions out unless explicitly requested.
5. Report any blocker or adjacent opportunity separately instead of silently taking it on.
