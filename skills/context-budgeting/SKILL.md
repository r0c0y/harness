# Context budgeting

1. Preserve user intent, safety constraints, current decisions, and unresolved blockers first.
2. Remove repeated logs, stale alternatives, and large irrelevant file regions.
3. Keep file paths, version identifiers, error messages, and verification evidence exact.
4. Label summaries as summaries and retain links to the underlying evidence.
5. Never compact away an explicit scope correction or pending user approval.
