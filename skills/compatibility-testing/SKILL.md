# Compatibility testing

1. Determine the supported versions from project metadata and official documentation.
2. Identify APIs or file formats that differ across the support matrix.
3. Select representative oldest, current, and materially different targets.
4. Use isolated tests and report targets not available in this environment.
5. Do not broaden support claims beyond the versions actually checked.
