# Developer onboarding

1. Confirm supported runtime, package manager, required configuration, and entry point.
2. Provide copyable steps for install, run, test, and verify in that order.
3. Give safe placeholders for secrets and point to their approved source.
4. Include the first likely troubleshooting check for each failure-prone step.
5. Validate commands from a clean or isolated workspace when possible.
