# Refactoring

1. Confirm the requested refactor goal and identify behavior that must remain unchanged.
2. Establish a passing baseline with existing tests or narrow observable checks.
3. Make one structural move at a time without mixing feature changes into the refactor.
4. Re-run checks after each meaningful step.
5. Stop when the intended structure is achieved; do not broaden the redesign.
