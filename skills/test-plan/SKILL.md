# Test plan

1. Start from acceptance criteria and changed trust boundaries.
2. Prioritize high-impact behavior, negative cases, and compatibility.
3. Map each risk to a test layer and an observable assertion.
4. Reuse existing test commands and avoid redundant checks.
5. Mark checks that require unavailable browsers, services, credentials, or hardware as planned but unrun.
